# Trainer Dashboard

A macOS-style trainer dashboard: a dock of app tiles at the bottom, and each app opens in its own draggable, resizable window.

Apps: **Settings**, **My Class**, **Cohorts** (sample data in `app.js`).

Run it by opening `index.html` in a browser; no build step. To add an app, add an entry to `APPS` in `app.js`.
