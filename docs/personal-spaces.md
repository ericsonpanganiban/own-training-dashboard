# Personal Spaces (planned, not built)

Goal: when the dashboard is shared, every person has their own private data. Only the owner changes the code.

- Share others as Contributor (can use the app and save data), never Editor (can publish code).
- Each person signs in with their Claude account; the page knows them through the `user` capability.
- Move all app data under each person's own space (`data/users/<id>/...`) so nobody sees anyone else's cohorts, quizzes, notes or notifications.
- Before switching, copy the owner's existing data into the owner's space so nothing is lost.
- Stay shared for everyone: Updates (release notes) and the default look (colorway, dock order, wallpaper).
- Slack and Google Drive already run on each person's own login.
- Touches every app (Coaching, Cohorts, Attendance, Quiz, Courseware, Notion, notifications), so it is a large change.

Also planned: a Dashboard menu at the top with Updates first (release notes the owner posts, with a "new" badge).
